## Concepts surfaced

- **Agentic OS** — a packaged, always-on operating layer of AI agents/skills/dashboards for running a business function (here: an agency), as opposed to a one-off automation or single AI workflow.
- **Claude Code as orchestration engine outside coding** — using Claude Code (an Anthropic CLI coding agent) as the general execution/orchestration backbone for non-coding business operations, wiring it to Obsidian and Google Suite.
- **Obsidian as agent memory** — using a local Markdown knowledge vault as the persistent memory/context store for an agent system (same underlying pattern this very Orbi vault uses).
- **"Skill" as productized delivery unit** — packaging an entire system's install + config as a single Claude Code Skill so a buyer doesn't need to assemble the stack themselves; positions "skills" as a monetizable software-delivery format, not just a Claude Code feature.
- **Sell-the-system vs. sell-the-automation** — a positioning/pricing narrative common in the AI-agency space: recurring infrastructure ("the system that produces automations") pitched as higher-value than one-off automation builds.
