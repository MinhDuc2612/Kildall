## Concepts surfaced

- Agentic harness: the runtime loop (plan → act → check its own work) that turns a bare LLM into a tool-using agent; the video frames Hermes Agent as this layer.
- Persistent/dialectic memory: giving an agent a memory store (Honcho) so it "learns" across sessions instead of resetting each conversation.
- Model-agnostic agent design: decoupling the harness from any single model provider (swap Claude/Codex/Gemini underneath the same agent).
- "Jarvis" framing: using the Iron Man AI-butler as shorthand for a personal, voice-capable, tool-connected home agent — a recurring pop-culture reference point for "agentic OS" builds.
