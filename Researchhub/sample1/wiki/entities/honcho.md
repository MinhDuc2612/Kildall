# Honcho

Open-source dialectic user-modeling/memory library (`plastic-labs/honcho` on GitHub) that Hermes Agent uses for its memory layer — agent-curated memory with periodic nudges and a deepening model of the user across sessions. A reel covering Hermes Agent's build stack mis-heard/mis-captioned its name on screen as "Hancho AI."
