# OmniRoute (diegosouzapw/OmniRoute)

A local, self-hosted, MIT-licensed AI routing gateway (built on Next.js) that exposes a single OpenAI-compatible endpoint (`/v1/*`) plus an Anthropic-compatible `/v1/messages` endpoint, routing requests across many upstream AI/LLM providers. Local-first by default. Supports many coding-tool integrations beyond chat APIs — Claude Code, OpenAI Codex, Gemini CLI, GitHub Copilot, DeepSeek, Groq, xAI, Mistral, and others. Per repo docs, can run as an npm package, Docker container, Electron desktop app, PWA, or on Android via Termux (unverified by adversarial re-check). Exact provider/model counts are disputed across sources (ranging from "40+" to "348 providers, 1,200+ models," with the largest numbers explicitly refuted by verification). Star-count claims (~50k+) are also unverified.
