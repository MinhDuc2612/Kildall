# Claude Code

Anthropic's coding-agent CLI, used across the source docs as the "engine" layer of a personal or business "agentic OS" — the thing that reasons and calls tools, wrapped with a memory vault, skills, scheduled routines, tool connectors, and (optionally) a dashboard or voice layer. It ships a first-party skills feature, a desktop-app "Routines" scheduler, and — as covered in depth in the sub-agent-system doc — an Agent tool (formerly Task tool) for spawning scoped sub-agents. Several docs in this folder deliberately genericize its name in prose (e.g. "a coding agent CLI") per an earlier user request, while retaining the real name in titles and Sources sections.
