# jsonmerge

An MIT-licensed Python library (on PyPI) for merging JSON documents with configurable per-field strategies (overwrite/append/arrayMergeById) — suggested as a way to mechanically merge OmniRoute's LLM-provider config with a public-apis-derived JSON manifest, since no pre-built integration between the two exists.
