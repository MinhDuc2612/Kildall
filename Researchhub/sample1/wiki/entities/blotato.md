# Blotato

A real, currently-operating multi-platform social media auto-posting API and dashboard built for AI-automation builders (the n8n/Make.com crowd). It pushes a finished AI-generated video or post out to multiple platforms (TikTok, Instagram, YouTube Shorts, X, LinkedIn, Facebook, Threads, Pinterest, Bluesky) from one call. No first-party n8n node exists for it — it's used via n8n's generic HTTP Request node, not a dedicated integration.
