# Claude Opus 4.8

The Anthropic model named in the title of Eddie Chen's "How I Built a JARVIS AI Operating System with Claude Opus 4.8" video, framed by the creator as the reasoning "brain" behind the Jarvis-style voice+HUD assistant, and separately referenced as the model Claude Fable 5 was found (per an open GitHub issue) to silently fall back to under some conditions — an undisclosed model substitution flagged as a quality-regression complaint.
