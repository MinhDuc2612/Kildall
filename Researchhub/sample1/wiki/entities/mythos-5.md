# Claude Mythos 5

Anthropic model, the more restricted, more dangerous sibling to Claude Fable 5. Per Anthropic's own account it "can find and exploit software vulnerabilities more effectively than any other model" and stays restricted to trusted "Glasswing" partners for defensive work only — not generally available.
