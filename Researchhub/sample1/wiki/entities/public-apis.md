# public-apis (public-apis/public-apis)

An MIT-licensed, community-curated GitHub repo — a markdown list of free public APIs organized into 40+ categories (Animals, Finance, Games, Weather, etc.), listing API name, description, auth type, HTTPS support, and CORS support. Not a gateway or runnable code, just reference data for developers picking APIs to integrate manually. No mention anywhere in the repo of OmniRoute or any AI-routing use case — the two projects are unrelated.
