# Anthropic

Maker of the Claude model family and Claude Code. Named directly (not genericized) in the source docs as the company behind Claude Fable 5 and Claude Mythos 5, the June 2026 export-control suspension and July 2026 redeployment of those models, the "Glasswing" industry jailbreak-severity framework, and first-party blog guidance on organizing Claude Code sessions ("Maximizing the value of your Claude Code sessions," "Auto mode is now the default in Claude Code").
