# Gemma 4

Google DeepMind's Gemma 4 26B-A4B, a Mixture-of-Experts model — the exact model Turbo Fieldfare (a native Swift+Metal Apple Silicon inference runtime) is hard-pinned to, running it in ~2GB of active RAM via expert streaming from a custom on-disk format.
