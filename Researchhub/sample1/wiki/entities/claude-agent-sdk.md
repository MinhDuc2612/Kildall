# Claude Agent SDK

One of three ways to define a Claude Code sub-agent (alongside filesystem-based `.claude/agents/` files and CLI-defined JSON): the `agents` parameter used when building agents directly in code via the SDK. Programmatically defined agents take precedence over filesystem-based ones sharing the same name.
