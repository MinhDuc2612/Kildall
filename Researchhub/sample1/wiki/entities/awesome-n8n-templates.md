# awesome-n8n-templates (enescingoz/awesome-n8n-templates)

A GitHub repo (346 n8n workflow JSON templates, 24.9k-star, CC BY 4.0 repo license — individual templates aggregated from elsewhere per the repo's own README) cloned into this vault on 2026-08-22. Contains ready-to-run workflows relevant to the multilingual-chatbot pattern (e.g. "Complete business WhatsApp AI-Powered RAG Chatbot using OpenAI," "AI Voice Chatbot with ElevenLabs & OpenAI for Customer Service and Restaurants," "SupportFlow Lite," a WordPress AI chatbot with Supabase/OpenAI) and, separately, an "AI Youtube Trend Finder Based On Niche" workflow that closely matches the viral-YouTube-idea-generator pattern — a 15-node LangChain AI Agent with a `youtube_search` tool that pulls and analyzes trending videos by niche. None of the chatbot templates wire in a booking/calendar step by default.
