# Amazon

Amazon researchers found a way to bypass Claude Fable 5's safeguards to identify software vulnerabilities — a "minor" jailbreak per Anthropic's own severity classification (accessing only routine defensive cybersecurity work, not Mythos-5-level capability) — which was among the triggers for the US export-control action that led Anthropic to suspend Fable 5 and Mythos 5 globally in June 2026.
