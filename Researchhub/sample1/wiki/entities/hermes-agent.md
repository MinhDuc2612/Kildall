# Hermes Agent

Real, actively developed open-source AI agent runtime built by Nous Research (`NousResearch/hermes-agent` on GitHub, MIT license), billed as "the self-improving AI agent." Model-agnostic, runs from a terminal, cloud VM, or $5 VPS, reaches the user through multiple chat/messaging platforms plus a CLI from one gateway process, and has a built-in learning loop that creates and refines skills from experience, agent-curated memory (via Honcho), a cron scheduler, and subagent delegation. Independently re-verified live against the GitHub API at 234,718 stars and 34,964 open issues — an exceptionally large number for an agent-runtime project.
