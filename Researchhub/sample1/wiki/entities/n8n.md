# n8n

A Berlin-founded (Jan Oberhauser, 2019) visual, node-based workflow-automation platform ("nodemation") — a more technical, self-hostable alternative to Zapier/Make, with 1,500+ integrations, native AI Agent nodes, and MCP client/server support. Licensed "fair-code" (Sustainable Use License). As of mid-2026: 150,000+ GitHub stars, a $2.5B valuation post-Series-C, and a further SAP strategic investment (May 2026) taking that to roughly $5.2B, with n8n now embedded inside SAP's Joule Studio. The awesome-n8n-templates repo is a 346-file library of ready-to-import n8n workflow JSON templates.
