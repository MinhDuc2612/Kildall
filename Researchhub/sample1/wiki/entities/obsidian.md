# Obsidian

The notes-vault-app product named directly in file titles ("Claude Code Obsidian voice command center") and video titles/Sources sections (e.g. "This Claude Code x Obsidian Agentic OS Will Be The New Meta") across the OrbiOS docs, even where body prose genericizes it to "a notes vault app" or "notes-vault-app plugin." Used as the memory/UI layer in several agentic-OS builds — a custom community plugin acting as a visual "command center" dashboard, and a Karpathy-style `raw/wiki/output` Markdown vault as the coding agent's navigation map. Whether it's actually the right memory layer is contested in community discussion (a Reddit commenter calls it "an outdated solution" versus a local-agent-memory harness).
