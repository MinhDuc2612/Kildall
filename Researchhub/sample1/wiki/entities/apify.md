# Apify

A scraping platform, compute-based + proxy passthrough pricing, with 6,000+ pre-built scrapers (LinkedIn, Google Maps, job boards) — wins on breadth versus do-it-yourself tools like ScrapeGraphAI, which wins on cost and flexibility instead. Also the scraping backend used inside an n8n lead-gen workflow (per Michele Torti's tutorial) to pull Google Maps leads by category. In a separate demo, scraping 998 companies cost $3.99 (~$0.004/company) via Apify versus $0.00 via ScrapeGraphAI with a local model.
