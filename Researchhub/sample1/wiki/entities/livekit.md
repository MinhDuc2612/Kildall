# LiveKit

Open-source real-time transport/room framework used as the shared "room" that a Python voice agent and a web-frontend HUD dashboard both join in the Jarvis-style build; state flows between them as data-channel events rather than REST polling. Named directly in the sub-agent-system-style (non-genericized) doc's wikilinks; genericized to "a real-time transport/room framework" in that doc's own prose per the vault's naming convention.
