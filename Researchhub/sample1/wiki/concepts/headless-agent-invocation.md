# Headless agent invocation

Triggering a coding-agent CLI via a one-shot, non-interactive command-line invocation (no open chat session) rather than typing into an interactive session. This is the actual mechanism behind essentially every "agentic OS" dashboard observed across the source docs — every UI button, voice command, or scheduled routine that "does something" is confirmed, independently, to be a headless call to the same CLI a human could type themselves; the dashboard contributes visibility and shareability, not any independent capability. A real, dated controversy is noted: the CLI vendor briefly billed headless usage against the API-credit tier instead of the flat-rate subscription plan, then reversed course.
