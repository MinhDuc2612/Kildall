# Skill packs

Packaged agent capabilities (built on a coding-agent CLI's first-party skills feature) used as a productized delivery unit for research, content, and data workflows feeding one team dashboard — install one skill package and get a pre-configured dashboard/workflow set, rather than assembling automations by hand. Named as the sellable unit in a marketer's "Agentic OS for your agency" pitch.
