# Multi-Provider Accounting Sync

The engineering pattern of syncing invoice/payment state across multiple accounting systems at once (e.g. Xero, QuickBooks Online, Rillet), rather than just generating a single invoice. Visible as active open-source engineering effort via a crbnos/carbon GitHub PR ("feat(accounting): multi-provider sync engine — Xero, QuickBooks Online, Rillet," merged 2026-08-03) — notable because generating and sending a single invoice is already a solved, table-stakes problem across mainstream invoicing SaaS, while cross-system sync is where the active work has moved.
