# Automate the Admin, Not the Relationship

The core onboarding-design principle observed across a watched 7-step agency-onboarding flow: every automated step (contracts, invoices, access provisioning, report generation) is pure administrative overhead with no relationship value in doing it manually, so it should be automated aggressively — while steps where relationship-building actually happens (the kickoff call itself, team intros) should stay human. For the invoicing step specifically, this extends to "automate invoice generation and status tracking fully; automate reminders only up to a defined threshold, then hand off to a human," since a wrongly-timed automated dunning message can do real relationship damage.
