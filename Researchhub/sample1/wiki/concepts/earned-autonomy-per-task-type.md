# Earned autonomy per task type

A staged-autonomy-governance mechanism: each task type is graded pass/fail, and a high success rate over a fixed number of runs unlocks unattended execution for that specific task type — concretely, 95% success over 20 runs unlocks full autonomy, and dropping below a 90% floor automatically reverts it to supervised mode with an alert. Not a global on/off switch — autonomy is earned and can be lost per task type independently.
