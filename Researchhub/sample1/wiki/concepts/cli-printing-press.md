# CLI printing press

A technique, credited to Lyft co-founder Matt Van Horn, for generating custom CLI-based connectors from scratch for platforms with no existing agent integration — used in the ARMS framework's Level 3 Applications maturity to build connectors for a fitness-tracking app and a school platform.
