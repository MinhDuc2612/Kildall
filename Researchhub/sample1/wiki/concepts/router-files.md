# Router files

A memory-organization technique from the ARMS framework's Level 2 (Memory): instead of human-oriented folder/file naming, a root router/context file functions as a router mapping "departments" (content, community, etc.) to relevant files, plus a dedicated router file per department listing relevant skills and reference files. The stated logic: agents parse files fast, so navigation should be optimized for the agent, not for a human's mental folder model — distinct from (though similar in spirit to) the separate `raw/wiki/output` + `index.md` vault convention used elsewhere.
