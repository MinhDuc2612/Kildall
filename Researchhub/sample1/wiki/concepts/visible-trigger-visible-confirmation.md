# Visible Trigger, Visible Confirmation

The principle that every automated onboarding step should be legible: sign → packet arrives; pay → access activates; form submitted → call auto-schedules. A "black box" automation that doesn't confirm it happened erodes the same trust it's trying to build. Extended to invoice reminders specifically: an automated reminder sequence also needs a visible off-ramp to a human after a defined number of unanswered nudges.
