# Adversarial self-testing (Sparring loop)

An autonomy-governance technique: separate builder and breaker agent roles, neither touching the other's output, so weaknesses get hunted deliberately rather than hoped away. Demonstrated concretely as the "Sparring loop" — one agent role implements, a separate role only hunts for weaknesses in yesterday's work, and the builder must fix whatever the breaker proves.
